Android application built with Kotlin and Jetpack Compose.

The project demonstrates working with REST APIs, CSV data processing, network requests, and multimedia playback.

## Features

* Modern UI built with Jetpack Compose
* REST API integration
* Network communication using Retrofit2 and OkHttp
* CSV data processing
* Multimedia playback using ExoPlayer
* Android application architecture and navigation

## Technologies

* **Kotlin**
* **Jetpack Compose**
* **Retrofit2**
* **OkHttp**
* **REST API**
* **CSV parsing**
* **ExoPlayer**
* **Android SDK**

## Project Structure

The project follows a modular and organized structure with separate components for UI, navigation, data processing, API communication, and application resources.

## Getting Started

1. Clone the repository.
2. Open the project in Android Studio.
3. Let Gradle synchronize the project.
4. Build and run the application on an Android device or emulator.

## Requirements

* Android Studio
* Android SDK
* JDK 17 or newer
* Internet connection for API requests
